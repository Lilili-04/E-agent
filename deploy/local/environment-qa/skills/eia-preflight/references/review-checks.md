# 整份环评报告审核清单

按项目主要环境影响选取检查项。每个主题先找报告的结论，再验证支撑链是否完整。先追可能改变评价范围、选址准入、污染防治方案或达标判断的线索。施工与运营、污染影响与生态影响可分别检查。专项审核只选相关主题。

| 主题 | 从哪里开始 | 要核对的问题 |
| --- | --- | --- |
| 项目身份和建设内容 | 封面、工程组成表、生产规模、平面布局、工艺流程 | 项目名、地点、建设性质是否一致。产能、设备数量、原辅料和年工时能否对应。主体、公辅、储运、环保与依托工程是否纳入评价范围。 |
| 评价范围和选址准入 | 位置图、红线图、规划或分区管控分析、保护目标表 | 工程范围、坐标和敏感目标是否使用同一位置口径。所称管控单元、规划条件或保护范围能否由适用官方资料和空间证据支持。报告配图或坐标不足时，指出需要补核的图层、边界或文件。 |
| 现状与监测资料 | 现状章节、监测报告及布点图 | 监测点位、时间、因子与评价对象是否对应。引用的是现场实测、既有监测还是公开数据。报告表与附件的数值、单位、检出限、统计数据是否一致。 |
| 工程分析与污染源 | 产污流程、物料与水平衡、污染源强计算表 | 工艺图中的产污节点是否都有去向。区分正常、启停、故障等工况。废气、废水及其他主要环境影响是否与产能、用量、运行时间和物料去向对应。 |
| 影响分析或预测 | 评价依据、预测输入、情景表、结果图表 | 污染源、源强、排口、时段及敏感目标与前文是否一致。说明的有利或不利情景是否进入实际计算。结论能否在对应点位、工况和统计时段的结果中找到支持。 |
| 治理设施和排口 | 治理工艺、设备参数、排口表、监测计划 | 逐个追查产生、收集、治理、排放或处置。处理对象、能力、去除效率及设计依据与预测负荷是否匹配。排口编号、位置、排放去向及监测因子在各表是否一致。 |
| 改扩建与排放总量 | 原有工程、现有许可或监测、拟整改措施、汇总表 | 核实各表的基线是许可量、实际量还是设计量。新增、保留、停用和削减对照实物工程。区分本项目增量与变化后的全厂总量，核对是否重复扣减或跨排放边界汇总。 |
| 固体废物、噪声与环境风险 | 废物产生及去向、声源和厂界结果、风险情景及应急措施 | 废物分类和处置去向是否有依据，产生量、周转周期和暂存能力是否对应。声源位置、运行时段、厂界或敏感点与预测条件是否对应。风险源、泄漏或事故情景与围堵、收集、应急方案是否衔接。按实际工程检查适用主题。 |
| 生态与施工 | 占地表、施工组织、保护目标、恢复方案及图件 | 对齐永久与临时占地、施工期与运营期、主体及附属工程。核对敏感目标的位置、受影响时段、影响路径、避让或恢复安排和监测要求。对图像证据不足的事项说明待核范围。 |
| 结论与措施落实 | 环保措施清单、监测表、汇总表、结论、有关附件 | 重要措施是否能在工程、排口或保护目标找到对应项。正文提出的工况限制、整改、投运条件及补充监测是否进入措施清单。对照总量、达标和环境影响结论所用的最终数据版本。 |

## 从表内复算走到全报告一致性

- **顺向检查。** 从项目设备或活动水平出发，把产污工序、参数、治理设施、排口、排放指标及汇总表串起来。识别同一设施处理多股物流、同一股物流跨多表重复出现、分流或回用的情况。
- **反向检查。** 从达标和总量结论反查对应的排口、预测工况、数据来源与标准条目。发现同名污染物数据不一致时，先按「阶段、设备或排口、物料流、工况、时段、单位」建立对应关系，再判断是否矛盾。
- **核对支撑强度。** 引用的检测报告、协议、图件或底表未附时，给出报告已经提供的证据和待补材料。找不到的内容先换关键词、查目录与续页。只在完整核对相应章节和附件后，才写明确缺项。

## 排序和归并

优先报告会改变选址或准入、评价结论、排放量或达标判断、措施可行性的事项。其次报告影响证据可信度、尚未确定是否改变结论的缺口。最后列一般表述、编号或格式问题。能追到同一个错误参数的多个表合并成一项，列出各处传播位置。审核范围由实际材料决定，抽查的项目注明抽查对象。

# 源强、排放量与水平衡复算

## 先确认方法和输入

先找到报告给出的核算方法及依据，例如产排污系数、物料衡算、实测、类比或设计参数。检查方法适用的行业、工艺、规模、治理条件、计量基准与工况。若报告采用系数法，优先核对系数是产污系数还是排污系数，活动水平是否和系数分母一致。已经反映治理效果的排污系数，按其适用条件使用，避免再次扣减。

建议按「变量｜原值及单位｜用于算式的值及单位｜报告页码、表号或其他依据｜工程、排口及工况」记录输入。将有明确出处的原值、从报告反推的值和临时假设分别标明。报告没提供取值依据时，可以复现它公开给出的数值并指出方法或参数仍待确认。

## 废气

按「产生环节 → 收集 → 治理 → 有组织排口或未收集去向」逐段追查。相同污染物出现在多个生产线或排口时，按排口和同时运行情景分组。

| 要核对的量 | 可用的算式和条件 |
| --- | --- |
| 系数法产生量 | 活动水平 × 产污系数。确认活动水平是产品量、原料用量、燃料量还是其他计量基准。同一股物料涉及多个工序时检查重复计入。 |
| 收集量及治理后有组织量 | 对仅有一条收集治理路径的简化情景，收集量 = 产生量 × 收集率，治理后有组织量 = 收集量 × (1 − 去除率)。发生旁路、分流或二次产生时分别列项。 |
| 未收集量 | 在只有收集和未收集两个去向时，未收集量 = 产生量 × (1 − 收集率)。其后是否全部计入无组织排放，按报告实际去向确认。 |
| 排放速率与浓度 | 同一工况和体积基准下，速率 kg/h = 浓度 mg/m³ × 风量 m³/h ÷ 10⁶。反算浓度用速率 × 10⁶ ÷ 风量。对照报告的风量和浓度口径，例如实际体积、标准状态、干湿基或基准含氧量。换算条件按适用依据取得。 |
| 年排放量 | 对排放速率可视为恒定的工况，t/a = 速率 kg/h × 该工况年运行小时 ÷ 1000。多个工况分别计算后相加，核实工况时段是否重叠及是否纳入年度汇总。 |

设计额定风量、实际工况风量和多管汇合后的风量可能不同。核对排放速率和浓度来自同一个排口及运行情景。共用排口按同时排放的质量流量与对应风量重新计算浓度。不同时运行的生产线分情景比较。多级治理可逐级核对质量，只有各级去除率都明确以各自进口为基准时，才依次乘剩余比例。

## 废水

先画清工作关系：工序来水 → 分质收集或预处理 → 汇合处理 → 回用、接管或直排 → 对应总量表。分别核对各股水量、浓度、污染物质量和去向。关注全厂排口与技改新增支路、企业接管口与污水厂尾水之间的区别。

| 要核对的量 | 可用的算式和条件 |
| --- | --- |
| 水量 | 日均水量 × 相应运行天数可求年度水量。批次排放用每批水量 × 批次，峰值和年均分别核查。报告按密度把质量折成体积时，核对密度依据。 |
| 污染物质量 | 对同一股水、同一时段，质量 t = 水量 m³ × 浓度 mg/L ÷ 10⁶。用年水量得到 t/a。多股水或时段分别计算质量后再合计。 |
| 治理效果 | 质量去除率 = (进口质量 − 出口质量) ÷ 进口质量。仅在进出水量相同且口径匹配时，可直接用浓度 × (1 − 去除率) 求出口浓度。水量变化时先算出口质量，再按实际出口水量反算浓度。 |
| 混合浓度 | 对实际汇合且时间窗口一致的来水，在汇合计算段没有其他质量变化时，混合浓度 = Σ(水量 × 浓度) ÷ Σ(水量)。算出的年加权浓度与瞬时浓度、批次浓度和实际排口监测值分开解释。 |
| 处理规模 | 对照进入设施的水量、峰值或批次负荷、运行时间及设施设计能力。各股水量的年度总和用于年度平衡，同一时间窗口的负荷用于校核处理能力。 |

遇到报告的处理效率相互冲突，可按每个有来源的值分别算。比如同一股水进水 240 mg/L、进出水量相同，60% 和 70% 分别得到 96 和 72 mg/L。再看该股水在后续表的浓度及年排放量各自支持哪个取值。若它只是技改支路，实际排口还需查全厂汇合、排放时段和适用限值。证据只够确认冲突时，把两种复算结果和需补依据一并列出。

## 水平衡、物料衡算与改扩建

- **水平衡。** 确定核查范围和统一时段。对全厂边界，外部进水应与排放、蒸发或其他损耗、产品带出及存量变化对应。内部回用既有来源又有去向，在相应局部节点计算，在全厂合计时抵消。对流程图逐节点检查进出；剩余差额结合原表精度及漏列支路查证。
- **物料衡算。** 统一计量基准，例如原料湿重、干重、有效组分或元素质量。核对输入、产品、废弃物、排放和库存变化。原料总质量与某一污染物质量分开记，原料含量和排放因子各自需要依据。无法解释的差额指出来源和影响。
- **改扩建。** 在同污染物、去向、时段和基线下，建成后量可以用「现有基线 + 新增量 − 退出或削减量」复核。若报告的「新增」已经是净增量，直接按净增量与基线相加。核对现有工程表、技改表、削减措施和建成后全厂表所采用的定义。实际量、许可量与设计量分别对照。

## 用计算工具留下可复核的输入和结果

用 `eia_calculate` 的 `variables` 记录 `name`、十进制字符串 `value`、`unit`、实际 PDF 页码 `page` 和 `source`。在 `formulas` 中给每个结果填写 `label`、`expression` 和 `unit`。例如变量 `C_in=240`、`eta=0.60`，等流量情景的表达式为 `C_in * (1 - eta)`。工具按给定表达式运算。百分数按算式转为小数，单位换算和公式适用性先自行核对。

中间结果保留有效精度，最终值与报告同精度比较。差异接近限值时，按适用依据核对有效数字和判定方法。可复现的结论应能追到「输入原值及出处 → 适用公式和假设 → 复算值及单位 → 报告值及差异 → 对排口、总量或结论的影响」。

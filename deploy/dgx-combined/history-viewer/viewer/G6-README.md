# G6 本地展示层

当前绘图使用 `@antv/g6` 5.1.1 的官方浏览器构建，MIT许可证保存在 `vendor/G6-LICENSE.txt`。来源、npm包完整性摘要和本地文件SHA256见 `vendor/g6-manifest.json`。页面从本机加载绘图库，无需外部CDN；没有新增npm工程或系统服务。

`g6-view.js` 通过实际 `G6.Graph` 绘制节点和关系。版本图按原有沿革日期提供初始坐标，G6负责渲染、拖动和视口；法规关联图使用G6的AntV Dagre自动分层布局。节点与关系标签点击后，沿用原查看器的metadata、证据及原文弹窗。支持拖动画布、拖动节点、缩放、适应画布及重置布局。时间线与列表保留。

数据仍来自已有只读接口，未增加、删除或推断任何法规事实，也不连接模型服务。重新选择法规或切换视图会销毁上一实例，避免残留画布与监听器。

验证记录见 `../data/graphiti-national-v1/g6-verification.json`；已在实际浏览器检查河道6节点5条版本关系、法典11节点10条跨法规关系、节点与关系标签取证、缩放和拖动后的连线更新。本地图谱接口仍与原导出一致。


## 第二版展示改进

保持原有图形风格，新增大图模式（可按钮或 Esc 退出）。Metadata 在宽屏时与图并排，在窄窗口时位于图下方；默认展示最新版本，点击节点、关系标签或记录索引可切换记录。保留核查状态、原因、独立的公布／修订／施行日期、机关、文号、类型、关系范围和原文取证，不新增数据库 metadata。

只有一个版本且存在跨法规关系的法规，默认展示法规关联图；多版本法规默认展示版本图。切换同一法规的视图不覆盖手动选择。关系标签新增事件生效日期、日期未知和待核查提示；未来日期标记“尚未到生效日”。详情以本机日历日期比较“生效日期已到／尚未到生效日”，仅提示记录的事件日期，不推断法规全文效力。说明区区分本图与该法规全部关系数量，并明确版本标识日期并非施行日期。
